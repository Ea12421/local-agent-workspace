# M8-20 用户可见观察补充

- **观察来源**：用户本人在当前 Codex App 中看到一个名为“沙悟净”的宠物。
- **观察内容**：宠物按钮/列表中出现“沙悟净”；进入后看到“更新”相关按钮，点击后出现一段更新指令文本。
- **已确认**：当前界面存在可见的“沙悟净”宠物。
- **仍未知**：
  - 当前显示的宠物是否来自本次审计包，还是此前已存在的相同安装；
  - “更新”按钮的确切动作和目标路径；
  - 更新指令是否会覆盖文件、改变配置或触发其他副作用；
  - 当前显示的资源是否已实际加载全部动画帧。
- **操作边界**：在准确读懂更新指令前，不点击更新、不执行弹窗中的指令、不覆盖现有宠物目录。
- **证据级别**：真实用户可见观察；不是自动化 Computer Use 回执，也不是更新动作成功证明。
