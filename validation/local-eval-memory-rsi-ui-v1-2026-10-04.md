# 本地评测与记忆接入 v1：用户可见闭环验证

日期：2026-10-04（Asia/Shanghai）

## 结果

通过。评测任务、评分、反馈摘要和历史记忆引用现在会从本地 RunEvent/Artifact 读回，并显示在现有“受控自动更新”卡片中。

## 用户能看到什么

- **评分**：固定评测当前显示 `4 / 4`。
- **评测任务**：显示 `rsi.fixed.proposal-integrity` 对应的任务名称。
- **历史参考**：显示本次候选引用的项目记忆条数。
- **反馈**：显示固定评测的反馈摘要。
- **回放**：通过运行 ID 重新读取时，API 同时返回事件和同一份 `evaluationBundle`（评测包），不会只剩一段静态文字。
